// EVAL + LINEAR AWARENESS

самоконтроль агента

eval protocol — T/R/C

binary pass/fail в конце каждого ответа:

◇ ctx: 48% | ◇540k | ●
▫ eval: T:✓ R:✓ C:○
▫ linear: AIM-2054 · speakers · ◐ IP
T
Text — структура, ясность, инсайты
R
Rules — naming, папки, стиль
C
Code — работает, минимализм

Linear awareness layer

задачи привязаны к сессии автоматически:

1
при старте сессии — hook подтягивает задачи из Linear
2
match по теме — контекст привязывается к тикету
3
footer показывает статус и рекомендации
4
/linear-action — update, close, comment

агент не меняет задачи автоматически — только suggest, человек подтверждает

// NAMING · VAULT

структура командного vault

ai-mindset-2026/
  AGENTS.md ← индекс
  aim-rules/ ← {rule}, {prd}, {skill}
  inbox/ ← {research}, {analysis}
  meetings/ ← {meeting}, {transcript}
  Labs/ ← когорты (f25, w26, s2)
  Org/ ← HR, Partners, Marketing
    HR/roles/ ← 8 карточек ролей
  Products/ ← Space, Circle, B2B

формат: {project} {type} description – YYYY-MM-DD.md

почему это работает

1
naming — агент ищет по паттерну {type}, не по содержанию
2
AGENTS.md — агент знает что где лежит
3
role cards — агент знает кто за что отвечает
4
Obsidian Sync — все видят изменения сразу

«когда выходишь на 2 человека — погрешности в названиях сразу критичны. просто всё ломается.»

— из разговора с Ирой
