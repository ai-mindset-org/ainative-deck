# Скилл — не хранилище фактов

Ответ Дениса на вопрос из зала: «скилл — это в принципе не место для хранения фактов; скилл — это описание сценария работы над данными» — когда его использовать, что нужно для выполнения, как сценарий работает и каковы критерии качества результата. Факты и файлы живут отдельно, в многоуровневой базе знаний: сырые данные (телеграм-чаты, почта, CRM) — неприкосновенный источник правды, а для агента строится нормализованный слой. Процесс превращается в полноценный скилл на следующей неделе (M2).
