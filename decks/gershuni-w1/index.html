// BITTER LESSON

масштаб vs экспертные правила

Исследователи всегда пытались вложить знания в систему — создавали правила, онтологии, экспертные системы. Каждый раз это давало кратковременный прогресс. Каждый раз метод, основанный на масштабе и вычислениях, побеждал в долгосрочной перспективе.

Rich Sutton — The Bitter Lesson, 2019
// Примеры
  • Шахматы — Deep Blue с экспертными правилами проиграл AlphaZero, обученному самоигрой без предустановленных знаний
  • NLP — лингвистические правила и синтаксические деревья проиграли трансформерам при масштабировании данных
  • Распознавание речи — фонетические модели проиграли нейросетям на больших корпусах
  • Зрение — ручные признаки (SIFT, HOG) проиграли CNN в 2012 на ImageNet
// Вывод
Инженерия знаний — тупик. Не потому что эксперты глупые. Потому что мир сложнее любой явной модели.
Масштаб данных + масштаб вычислений > любая экспертная система. Это не мнение. Это эмпирический закон последних 30 лет.

// ML VS LLM

фундаментальное различие

Machine Learning
классический ML
Обучается на структурированных данных, предсказывает значения. Логика детерминирована: одинаковый вход всегда даёт одинаковый выход.
  • Скоринг кредитных заявок
  • Рекомендательные системы
  • Fraud detection
  • Прогноз оттока
Автоматизирует повторяемое — задачи с чёткой формулой и известными паттернами
vs
LLM
генеративный ИИ
Обучается на тексте всего интернета, генерирует. Недетерминированное рассуждение: понимает контекст, работает с новыми задачами.
  • Понимание неструктурированного текста
  • Принятие решений в новых ситуациях
  • Многошаговые рассуждения
  • Генерация кода, анализ, синтез
Автоматизирует то, что требовало суждения — задачи, где раньше нужен был человеческий эксперт
