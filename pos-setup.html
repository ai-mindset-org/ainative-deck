// block 02 · barriers to access

Барьеры доступа: zero friction

«Если вы 3 минуты думаете, набрать ли что-то – вы не экспериментируете. А если не экспериментируете – не видите возможности.»

01

Raycast

Cmd+Space → набираешь → ответ. Zero friction. POS level 0 – доступ за 0 секунд.

02

Voice Input

Голосовой ввод – фундаментальная сущность. Звонки = данные. Krisp/Granola → транскрипт → summary.

03

Базовая скорость

Если набираете 30 слов/мин – это ваш bottleneck, не модель. macOS hotkeys, автозамена.

METR: −19% скорость, +20% ощущение — люди чувствуют что быстрее, но объективно медленнее. Причина — friction доступа.

// три режима ввода

keyboard → voice → parallel

В агентской среде мы не только печатаем — мы говорим, скроллим и переключаемся между потоками

01
Keyboard
Caps Lock → Hyper key (Karabiner). Home row shortcuts. Cost 2–4 сек → 0.5 сек. 80% пользы, 0 руб.
02
Voice
WISPR Flow + беспроводной микрофон. Диктуешь промпт стоя — 3x быстрее печати. Голос = новый keyboard.
03
Parallel
Голос + текст одновременно. Диктуешь промпт — руки правят код. iTerm split: 4–6 агентов параллельно.

Naming: без правил ничего не работает

«Если у вас нет naming convention – ваш vault за 2 недели превратится в свалку. А агент не найдёт ни один файл.»

Format

# pattern
{project} {type} description – YYYY-MM-DD.md

# examples
{AIM} {analysis} Sprint Audience – 2026-03-23.md
{personal} {note} morning reflection – 2026-03-24.md
{AIM} {rule} Communication Style – 2026-01-15.md

Why it matters

01
Агент ищет файлы по паттерну – без naming он слепой
02
Переход на 2 человека ломается если naming разный
03
Дата в конце → хронологическая сортировка автоматом
04
{project} {type} → фильтрация по любому измерению

CLAUDE.md – конституция для агента

~/.claude/CLAUDE.md
# Global Claude Code Rules
 
## Naming Convention
Format: {project} {type} desc – YYYY-MM-DD.md
 
## Communication Style
- Без корпоративщины
- EN DASH (–) вместо тире
- Конкретно: кто, что, когда
 
## Forbidden Actions
- NEVER create new folders
- NEVER send to channel #1877517944
 
## Strategy
Mission: build AI-native education...

Это не промпт

Это описание того, как вы работаете. Агент читает при каждом запуске.

Стратегия = операционная

Раньше видение было шелухой для IPO. Сейчас агент принимает решения на его основе.

Guardrails level 0

«Агент галлюцинирует» → нет памяти. «Небезопасно» → нет guardrails. CLAUDE.md решает оба.

Moat ≠ модель. Moat = ваш контекст и правила.
