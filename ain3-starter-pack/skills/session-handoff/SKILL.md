# Session handoff

1. Record objective, completed state and unresolved work.
2. Record repo, branch, base commit and dirty/clean status.
3. Link canonical artifacts and source snapshots.
4. Capture decisions in chronological order; newest explicit user instruction wins.
5. Add exact bootstrap, run and QA commands.
6. Separate public-safe context from private session paths and credentials.

Done when the next model can verify state before changing files.
