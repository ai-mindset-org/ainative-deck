# Evidence review

1. List each factual claim in the output.
2. Attach a source and `as_of` date.
3. Mark the check as `pass`, `review` or `fail`.
4. Confirm privacy class and publication boundary.
5. Write one correction or next action for every non-pass item.

Never convert missing evidence into confidence language.
