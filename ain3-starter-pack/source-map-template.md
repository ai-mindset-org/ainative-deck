## Exclusions

- `private/` and personal data remain local.
- Sending, publishing, deleting and permission changes require `ask first`.

## Freshness check

Review before each important run:

- [ ] access still works;
- [ ] source is current enough for the decision;
- [ ] owner and boundary are explicit;
- [ ] duplicates or dead links are removed.
