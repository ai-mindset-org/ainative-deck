# AIN3 World — правила игры

Это общий контекст-граф лабы. Он начался с утренней практики Дениса (M1, 14.07.2026): агенты разложили лекцию на 38 узлов. Теперь узлы добавляют участники — руками своих агентов.

**Смотреть граф:** https://ai-mindset-org.github.io/ainative-deck/ain3-starter-pack/graph/?src=../data/world-manifest.json

## Как добавить свой узел

1. Форкни репозиторий `ai-mindset-org/ainative-deck`.
2. Добавь ОДИН файл в `ain3-starter-pack/world/` по правилам ниже.
3. Открой pull request. После мержа манифест пересобирается автоматически, узел появляется в графе.

## Правила листа (контракт)

- **Имя файла:** `{namespace}-{slug}.md` — строчные латинские буквы и дефисы. Namespace один из: `technical` (артефакты, инструменты) · `market` (кейсы, экономика) · `people` (люди) · `concept` (рамки, определения).
- **Плоская папка:** никаких подпапок.
- **Frontmatter** (обязательные поля):

```yaml
---
type: leaf
namespace: concept
source: "откуда факт: лекция, практика, свой опыт"
confidence: 0.8
asserted_by: "имя вашего агента или модели"
extracted_at: 2026-07-14
---
```

- **Тело:** заголовок `# ...` + 2–4 предложения по-русски. Граф — это проза, узел — короткий.
- **Связи:** минимум 2 wikilink в секции `## related` — один на хаб вашего namespace (`[[concept-hub]]`), один на существующий соседний узел. Узел без связей — остров, его не примут.
- **Не редактируй чужие узлы** и хабы — только добавляй свои. Сырые источники (транскрипты) в граф не коммитятся: только короткий синтез.

## Промпт для твоего агента

Скопируй агенту (Claude Code / Cursor / Codex):

> Форкни и склонируй github.com/ai-mindset-org/ainative-deck. Прочитай ain3-starter-pack/world/AGENTS.md и 3–4 существующих узла как образец. Создай один узел про [ТВОЯ ТЕМА: инсайт с лекции, твой процесс, твой инструмент] по контракту из AGENTS.md: правильное имя файла, frontmatter, 2–4 предложения, минимум 2 wikilink на существующие узлы. Открой pull request с одним файлом.

## Пример узла

Смотри любой файл рядом, например `concept-think-in-processes.md` — образец формата, длины и связей.
