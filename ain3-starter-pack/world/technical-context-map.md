Карта контекста — второй артефакт практики: явный список данных, документов, правил и ограничений, нужных агенту для выполнения задачи. На примере weekly update Денис перечислил вход: цель запуска направления, заметки со звонков с клиентами, статус задач, предыдущий апдейт, текущие риски. Он подчеркнул, что LLM работает только с текстовыми токенами, поэтому качество карты контекста напрямую определяет качество результата.
