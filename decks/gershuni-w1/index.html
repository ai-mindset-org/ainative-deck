// BITTER LESSON

масштаб vs экспертные правила

Каждый раз метод, основанный на масштабе и вычислениях, побеждал экспертные правила в долгосрочной перспективе.

Rich Sutton — The Bitter Lesson, 2019
// Примеры
  • Шахматы — AlphaZero без знаний побеждает Deep Blue
  • NLP — трансформеры побеждают лингвистические правила
  • Речь — нейросети побеждают фонетические модели
  • Зрение — CNN побеждают ручные признаки (2012)
// Вывод
Инженерия знаний — тупик. Мир сложнее любой явной модели.
Масштаб данных + вычислений > экспертная система. Эмпирический закон 30 лет.

// ОГРАНИЧЕНИЯ LLM

что LLM не могут

01

Определить цель

LLM оптимизирует под заданную метрику. Выбрать, какую метрику оптимизировать — решение человека.

02

Нести ответственность

Ни одна правовая система не поддерживает accountability агента. Последствия всегда возвращаются к человеку.

03

Суждение в новизне

Задачи без прецедентов и с оспариваемыми критериями. Где нет паттерна для интерполяции.

04

Физический мир

Манипуляция объектами, навигация в реальном пространстве. Роботика — отдельная задача.

05

Заменить весь ML

Классический ML для структурированных данных, скоринга, fraud detection. LLM не заменяет, а дополняет.

06

Иметь состояние

Без обвязки LLM — stateless функция. Память, персистентность, контекст — задача harness.
