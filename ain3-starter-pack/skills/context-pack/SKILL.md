# Context pack

1. Read the process brief and source map.
2. Write five fields: `goal`, `current`, `rules`, `examples`, `boundary`.
3. Link sources; do not copy raw private material into the pack.
4. Add one `next_action` that can be checked.
5. Save using the project naming convention.

Done when another agent can name the current state, boundary and next action without guessing.
