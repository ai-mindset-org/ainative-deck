# Step 3 — 3 фокуса + 1 skip + energy map
# Step 4 — generate HTML card (5 styles)
# Step 5 — Playwright → PNG @2x DPR
# Step 6 — Telethon → photo + caption
# Step 7 — cleanup temp files

5 визуальных стилей

timeline — расписание по часам (3+ встреч)
convergence — линии от проектов к центру (пт)
bento — сетка мини-панелей (разный день)
radar — кольца приоритетов (deep work)
minimal — только текст (low energy)

auto-accent по типу дня

● urgent/launch → red
● deep work (≤2 meetings) → blue
● strategy → purple
● default → amber

weekday logic

пн → overview · вт → deep work · ср → midcheck
чт → sprint · пт → summary · сб/вс → minimal
