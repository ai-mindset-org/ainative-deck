# personal vault – как устроен волт Александра

> ответ на вопрос из чата AIN3: «какие сущности, какие правила, ведущие файлы, узлы». разбор по мотивам воркшопа personal set up (14.07.2026). структура выросла из аудита и плана рефакторинга; копировать её целиком незачем – берите принципы, свою форму подскажут ваши процессы.

## масштаб

два волта, оба в git: личный (~13 500 заметок) и командный (~5 000). переключение – через Obsidian, синхронизация – обычные коммиты. знания живут в волте; тяжёлые медиа, сборки кода и серверное состояние живут в отдельных слоях снаружи.

## сущности: тип зашит в имя файла

каждый файл несёт тип прямо в имени:

```
{проект} {тип} описание – YYYY-MM-DD.md
{AIM} {meeting} weekly sync – 2026-07-14.md
{rule} file naming convention.md
{transcript} {krisp} практика M1 – 2026-07-14.md
```

имя работает как строка индекса: агент и человек понимают содержимое до открытия. основные типы: `transcript` · `meeting` · `rule` · `guide` · `analysis` · `overview` · `prd` · `decision` · `research` · `handoff`. дата – всегда в конце.

## четыре слоя (онтология)

каждая заметка принадлежит одному слою:

| слой | вопрос | что лежит | правило |
|---|---|---|---|
| raw | какие свидетельства? | транскрипты, клиппинги, войсноты, AI-чаты | неприкосновенен: после создания файл не редактируется |
| knowledge | что истинно? | правила, справочники, карточки людей | каждый факт со ссылкой на источник в raw |
| engagement | что произошло? | встречи, переписки, события | хронология, привязка к людям |
| working-memory | что делать дальше? | задачи, саммери, планы | протухает: у записей есть срок жизни, слой чистится |

движение всегда в одну сторону: raw → knowledge / engagement → working-memory.

## ведущие файлы (узлы)

- **CLAUDE.md / AGENTS.md** – конституция волта: правила именования, карта папок, границы. агент читает её до первой задачи; человек – при онбординге.
- **rules/** – правила живут как отдельные файлы (naming convention, онтология, протоколы). на правило можно сослаться wikilink-ом.
- **_inbox/** – вход без трения: всё новое падает сюда, разбор по папкам – отдельным проходом.
- **_templates/** – шаблоны заметок под типы.
- **память агента** – отдельный слой с фактами о предпочтениях и проектах; агент сам его пополняет и перечитывает на старте сессии.

## правила движения

1. сырые данные неприкосновенны – синтез пишется рядом новой заметкой со ссылкой на источник.
2. новые папки руками не создаются – структура меняется решением, агентам это запрещено правилом.
3. wikilinks обязательны: заметка без связей – остров, её никто не найдёт.
4. слой синтеза (короткие связанные заметки) поддерживают агенты; человек проверяет и правит правила, а не каждую заметку.
5. каждое большое перемещение файлов – с распиской: что, откуда, куда, сколько, как проверить.

## с чего начать свой волт

три вещи на первую неделю: naming convention (одно правило имени), папка `_inbox` (вход без сортировки), файл-конституция `AGENTS.md` (правила для агента). дальше структура вырастает из аудита реальных потоков – транскрипты, встречи, задачи сами покажут, какие папки нужны.
